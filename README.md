# Things I haven't finished · 未完成的事

一个用 p5.js 做的小作品：**把没做完的事，想象成漂浮在脑海里的星体。**

它们不排队、不打勾、不催你。它们各自绕着一个看不见的中心缓慢公转，有的轻快，有的沉。

在线玩：https://amyzw725-rgb.github.io/things-i-havent-finished/

---

## 怎么玩

- **点一颗星体** —— 选中它，它会改为绕画面中心公转。
- **点空白处** —— 取消选中。
- **点页面下方那行很小的 `LET GO`** —— 松开它。星体会停止运动、加速下坠，落进画面底部那片安静的空白里。

`LET GO` 不是按钮，是一行可以触发的字：没有选中任何东西时，它淡到几乎看不见。

---

## 三个「感觉」，而不是三个数字

这个作品刻意不显示任何进度、计数或百分比。所有状态都只通过视觉传达：

| 机制 | 想表达的感觉 | 怎么做的 |
| --- | --- | --- |
| **压力** | 没做完的事越多，脑内空间越紧 | 轨道整体向内收、允许彼此靠得更近、光晕略强、公转略快 |
| **呼吸** | 压力大的时候，那种隐约的「不安静」 | 速度做极小的周期起伏，光晕缓慢一明一暗；事情做完，呼吸也慢慢停下来 |
| **重量** | 拖得越久的事，越沉 | 由「已经在清单里待了多久」决定：越老越大、越慢、整条轨道略微下沉 |

所有这些都随未完成数量**缓慢**变化，不会突变。松手之后是「缓缓松开」，而不是一下就散开。

---

## 技术

- 原生 HTML / CSS / JavaScript，**没有框架、没有构建工具、没有后端**。
- p5.js 已本地化到 `lib/p5.min.js`，所以断网也能打开，也可以直接双击 `index.html` 运行。
- 星体的位置由**相位直接算出**（运动学模型），而不是用转向力去逼近轨道——这样它们永远在稳定地走，不会卡住、不会挤成一团。

```
p5-simple/
├── index.html     页面骨架 + LET GO 文字入口
├── style.css      深空视觉基调
├── sketch.js      全部逻辑
└── lib/p5.min.js  p5.js v1.11.3（本地）
```

## 本地运行

双击 `index.html` 即可。或者起一个静态服务：

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```
